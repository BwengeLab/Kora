# External Collaborator — UI/UX, Navigation & Features

*Experience name: "Shared Portal." An outside party (lender, external auditor, advisor) who sees **only** what the org shares via a consent grant. The proof that **few permissions still = a premium, complete experience** — not a barren page. Entry on sign-in → **Home** (the shared artifact).*

---

## Navigation (minimal, by design — but rich on what's there)
Home (the shared artifact) · Access & Requests · + copilot (scoped), notifications. *(No internal finance nav — they only ever see the granted artifact.)*

---

## Pages / screens

### Home — the shared artifact
What "Home" *is* depends on the consent grant's sub-type:

**If a Lender → a premium Credit Passport portal**
- **Purpose:** assess the business's creditworthiness with confidence.
- **On it:** **business health score gauge** + sub-scores (payment behavior, financial strength, risk profile, credit readiness); **revenue/cashflow trend charts**; **affordability estimate with its assumptions explained**; **evidence pack** (each score factor → its evidence); last-updated + data scope; **expiry notice**.
- **Features/functions:** drill any score factor → evidence; download the passport (if permitted); **request additional scope** (sent to the org to approve); see when access expires.
- *This is a complete, beautiful credit-assessment experience — focused, not thin.*

**If an External Auditor → an audit-pack workspace**
- **Purpose:** review the shared, scoped audit evidence.
- **On it:** scoped audit log + evidence, approvals trail, exportable audit pack, scope + expiry.
- **Features:** filter/search the shared evidence, export the pack, request more scope.

**If an Advisor → the scoped data the org shared** (reports/figures) in a clean read-only viewer.

### Access & Requests
- **Purpose:** transparency on what they can see and for how long.
- **On it:** active grant (data categories, period, **expiry countdown**), access history, **request more access** form.
- **Features:** request additional scope/time; see grant status; nothing hidden.

---

## Navigation / workflow flow
1. Sign in → **Home** = the shared artifact (Credit Passport / audit pack / scoped data).
2. Review it; **drill into evidence** for any figure; **download/export** if allowed.
3. Need more? **Request additional scope** → the org's Owner/Finance Lead approves or denies.
4. Access **auto-expires** at grant end (or instant revoke) → portal shows "access ended."
> Everything is **read-only, consent-scoped, time-boxed, revocable**, and **every access is logged** in the org's audit trail.

## Features & functions summary
View the shared artifact (rich, complete) · drill to evidence · download/export (if permitted) · request more scope/time · see expiry & access status. **Cannot:** see anything outside the grant, take any action on the org's data, or persist access beyond the grant.

---

## Why this matters
A lender opening Kora sees a **polished, complete credit-assessment portal** — arguably one of the most premium experiences in the product — despite having essentially one permission. This is the standard for *every* low-permission role: **focused and few ≠ poor; it means deeper and more crafted.**
